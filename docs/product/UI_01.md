# SOURCERUNE UI_01

Status: current approved engineer-oriented scene layout.

## Visual structure

```text
┌───────────────────────────────────────────────────────────────────────┐
│ LEFT                 CENTER / MAIN                         RIGHT       │
│ Source               Scene View                           IN / OUT    │

│ Wall / Cover         DAW Sync                             Peak        │
│ Space / Environment  Start / Closest / End                RMS / LUFS  │
│                                                                        │
│                      Spectrum / Space Response / Signal Flow           │
├───────────────────────────────────────────────────────────────────────┤
│ Motion | Bad Signal | Condition | Intelligibility | Ambience | Mix   │
│ Advanced EQ / Tone                                                    │
└───────────────────────────────────────────────────────────────────────┘
```

## UI_01 design intent

- Professional recording/mixing/post-production tool.
- Dark engineer-oriented appearance.
- No decorative "AI-generated" illustration language.
- Scene View is functional, not decorative.
- Central Scene/Motion area gets visual priority.
- Left side is a compact scene/source selector, not a giant asset browser.
- Right meters remain fixed and readable.
- Important numeric values remain permanently visible.
- Use technical mono/simple glyphs rather than emoji-like iconography.
- Avoid rainbow dashboard framing; inactive modules remain visually restrained.

## UI_01 function placement

### Left column
1. SOURCE
2. TRANSMISSION
3. WALL / COVER
4. SPACE / ENVIRONMENT

Each selector exposes the active model/type and its bypass/enable state.

### Center top — Scene View
Required:
- Source and listener relationship.
- Motion path.
- Approach / Pass By / Leave / Manual.
- Start / Closest / End.
- DAW Sync.
- Distance value.
- Speed value.
- Doppler value.
- Width/Perspective value.
- Set Start / Set Closest / Set End interaction.

The Scene View must remain useful in 2D even if a later 3D mode is added.

### Center analysis tabs
- SPECTRUM.
- SPACE RESPONSE.
- SIGNAL FLOW.

`SIGNAL FLOW` must display the actual processing order:
Transmission → Source → Condition → Cover → Motion/Distance → Space → Ambience → Intelligibility → Tone → Mix.

### Right fixed meter area
- IN.
- OUT.
- Peak.
- RMS.
- LUFS.
- Click/reset peak behavior can be added without moving the meter area.

### Bottom control strip
- MOTION.
- BAD SIGNAL.
- CONDITION.
- INTELLIGIBILITY.
- AMBIENCE.
- MIX.
- ADVANCED EQ / TONE.

The bottom strip is for fast session work: high-value macros and current values, not every internal DSP parameter.

## UI_01 parity

UI_01 must be implemented for both:
- VST3 native UI.
- WEB App / WEB TEST.

The geometry may adapt to browser/window size, but the same controls and state meanings must be preserved.
