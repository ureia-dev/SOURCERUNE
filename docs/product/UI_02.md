# SOURCERUNE UI_02

Status: **recognized historical second layout; functionally first-class alongside UI_01.**

## Identity

UI_02 is the previously discussed scene/spatial-visual version with a large city/night acoustic scene treatment. It is not an empty placeholder and must not be implemented by merely duplicating UI_01.

Its defining visual/function language is:
- large Scene View,
- 3D View / Top View switching,
- Source and Listener visualization,
- path / distance visualization,
- Start / Closest / End motion points,
- Motion mode such as Pass By,
- Distance / Speed / Doppler / Width readouts,
- SOURCE / TRANSMISSION / WALL-COVER / SPACE selectors,
- analysis views,
- metering,
- lower macro modules.

## Functional parity

UI_02 uses the exact same DSP, parameters, state schema and presets as UI_01.

Required modules:
- Source
- Transmission
- Condition
- Wall / Cover
- Distance / Motion
- Space / Environment
- Ambience
- Intelligibility
- EQ / Tone
- Mix
- Spectrum
- Space Response
- Signal Flow

- A/B/C/D snapshots
- Preset/state management
- VST3 and WEB state compatibility

## Scene area

UI_02 gives more visual priority to the live acoustic scene than UI_01.

The scene region must support:
- 3D View
- Top View
- Source marker
- Listener marker
- source-to-listener path
- Start / Closest / End positions
- distance visualization
- Approach / Pass By / Leave / Manual
- DAW/WEB timeline relationship
- selected cover/space context where useful

This remains a functional runtime visualization. Static Scene Preset Hero artwork is used for preset browsing/preview, not as a replacement for the live scene engine.

## Shared-state rule

Switching UI_01 ↔ UI_02 must not:
- alter sound,
- remap parameter IDs,
- reset parameters,
- change preset meaning,
- change deterministic seed,
- change automation behavior.
