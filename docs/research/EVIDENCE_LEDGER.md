# SOURCERUNE Research Evidence Ledger

Status: ledger created; large-scale population is still pending.

Method:
1. collect problem-language discussions across post-production, sound-design, game-audio and mixing communities;
2. deduplicate reposts, mirrors and repeated claims;
3. separate user workflow evidence from vendor marketing;
4. record source, date, topic, claim, design consequence and provenance;
5. use competitors only as workflow/function references;
6. mature research target is on the order of ~1000 deduplicated discussions/sources;
7. never claim that count until the ledger actually contains it.

Priority source families: Gearspace/Gearslutz, KVR, Reddit AudioPost/SoundDesign, Avid DUC, Creative COW, VI-Control, Cockos/Reaper, game-audio communities, books/papers, official manuals and vendor documentation.
