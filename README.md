# SOURCERUNE

SOURCERUNE is a new audio-post/worldizing plugin project focused on source transformation, transmission, occlusion, distance and motion, acoustic space, ambience, intelligibility, and reliable DAW automation.

## Project status

Architecture and repository structure are being locked before implementation. No DSP implementation is committed yet.

## Initial targets

- C++20 / JUCE-based architecture
- VST3 and AAX as first-class plugin formats
- Low-CPU native sample-rate processing
- Deterministic state, automation, offline-render, and recall behavior
- Modular scene engine with testable DSP stages

See `docs/architecture/PROJECT_STRUCTURE.md` and `docs/architecture/STRUCTURE_REVIEW_100.md` before adding implementation files.
