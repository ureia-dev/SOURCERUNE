# UI_01 Image Assets

UI_01 uses the approved professional restrained V2 artwork.

Nominal runtime image crop: **384 × 144**.

The four left-rail cards bind SOURCE, TRANSMISSION, WALL_COVER and SPACE_ENVIRONMENT assets. SCENE_PRESET_HERO assets belong to preset browsing/preview and must not replace the live Scene View.

All text and state badges are rendered by code, not baked into runtime PNGs.
