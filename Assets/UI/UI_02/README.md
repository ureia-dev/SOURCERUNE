# UI_02 Image Assets

UI_02 uses the same semantic asset IDs and audio state as UI_01, with larger scene-oriented crops.

Nominal runtime image crop: **512 × 256**.

UI_02 keeps its live 3D/Top spatial visualization, source/listener markers and motion/path controls. SCENE_PRESET_HERO assets are preset preview artwork, not a substitute for the live spatial view.

All text and state badges are rendered by code, not baked into runtime PNGs.
